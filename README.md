# Observatório GRAPROHAB v1

Aplicação estática de pesquisa. Abra `index.html` localmente por um servidor HTTP ou publique no GitHub Pages.

## Publicação no GitHub Pages
1. Crie um repositório público.
2. Envie o conteúdo desta pasta para `main`.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` / root.
4. Salve e aguarde a publicação.

O site usa Chart.js por CDN e os dados agregados em JSON.
